## 📖 Overview

**SpringCard.PCSC.Forms** is a .NET library developed by SpringCard, providing Windows Forms components for easy integration of PCSC (Personal Computer/Smart Card) functionality in desktop applications. This library includes user interface components for smart card reader selection and management.

Originally developed for internal use at SpringCard, this library has been made available to facilitate PCSC integration in .NET Windows Forms applications.

---

## ✨ Features

### Windows Forms Components
- **Reader Selection Form**: Pre-built form for selecting smart card readers
- **User-Friendly Interface**: Easy-to-use components for PCSC operations
- **Visual Feedback**: Status indicators and progress notifications

### PCSC Integration
- **Seamless PCSC Access**: Full integration with SpringCard.PCSC library
- **Event-Driven Architecture**: Automatic notifications for card insertion/removal
- **Reader Management**: Detect and manage multiple smart card readers

### API Design
- **Windows Forms Native**: Designed for Windows Forms applications
- **Easy Integration**: Simple to integrate with existing Windows Forms projects
- **Extensible**: Can be customized and extended as needed
