## 📖 Overview

**SpringCard.PCSC.ZeroDriver.Forms** is a .NET library developed by SpringCard, providing Windows Forms components for the ZeroDriver PCSC implementation. This library combines the advanced driver capabilities with user-friendly Windows Forms interfaces.

Originally developed for internal use at SpringCard, this library has been made available to facilitate advanced PCSC operations with visual components in .NET Windows Forms applications.

---

## ✨ Features

### Windows Forms Components
- **Reader Selection Form**: Pre-built form for selecting smart card readers with advanced options
- **Configuration Dialogs**: UI for configuring transport protocols and connection settings
- **Status Monitoring**: Visual indicators for connection and communication status

### ZeroDriver Integration
- **Full Driver Support**: Complete integration with SpringCard.PCSC.ZeroDriver
- **Protocol Selection**: UI for selecting and configuring transport protocols
- **Advanced Settings**: Access to all ZeroDriver configuration options

### Multi-Protocol Support
- **CCID Over USB**: USB communication interface
- **CCID Over Bluetooth**: Bluetooth connection setup
- **CCID Over Network**: Network configuration
- **CCID Over Serial**: Serial port settings

### API Design
- **Windows Forms Native**: Designed for Windows Forms applications
- **Easy Integration**: Simple to integrate with existing projects
- **Extensible**: Can be customized and extended
